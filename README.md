# 南师柚园

南京师范大学专属校园论坛。认证后设置昵称与头像，再进入首页。

## 功能

- **认证**：姓名 + 专业 + 入学年份
- **资料**：昵称、预设头像或上传头像（进入主界面前必填）
- **校园周边生活**：先进入大类，再选商场 / 娱乐地点 / 美食
- **选课攻略**：课程名、类型（好课 / 壁垒 / 给分 / 避雷）由同学自行填写
- **校园生活**：宿舍、社团、图书馆、闲置、失物招领等校内话题

数据保存在浏览器本地，适合课堂演示与本地使用。

在线地址：https://nnu-youyuan.pages.dev/

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端里提示的本地地址即可。

在 Cursor 里改完代码后，把更改推送到 GitHub 的 `main` 分支，公网页面 https://nnu-youyuan.pages.dev/ 会自动更新。
